# Introduction
This directory contains the 3D printed parts and printing instructions for Boris.

The main file is `boris.blend`, the components of which are exported to a number of `boris*.stl` files at a Blender scale factor of 1000 to give real size in millimetres.

# Printing
- `boris_cigar.stl`, `boris_box.stl`, `boris_box_lid.stl`, `boris_cigar_support.stl` and `boris_box_usb_c_hole_cover.stl` should all be printed in ASA, brown for `boris_cigar.stl`, the rest any dark colour (I used \[black\]), 15% in-fill, fastest speed, supports on the build plate,
- `boris_heart.stl` should be printed in ASA, black of course, with only 5% in-fill: the lighter the better,
- `boris_cigar_tip.stl`: should be printed in transparent PETG, following the advice (here)[http://www.meades.org/misc/big_round_button/big_round_button.html#transparent_petg_printing] for maximum transparency, supports on the print bed.
